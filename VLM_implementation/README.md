# VLM_implementation (experimental)

This folder holds standalone VLM stop / semantic experiments (Qwen, MiniCPM, harness
prompts, install helpers). It is **not** part of the live Go2 stack.

The production path is SAM2 + UniDepth via `stop_judge.py`, launched by
`python go2_nav.py`. See the stack guide: [`../../README.md`](../../README.md).
